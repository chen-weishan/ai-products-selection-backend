共通前提：後端已有 springdoc-openapi，spec 在 /api/v1/v3/api-docs；前端 Angular 21 standalone。

版本 A：後端還沒補 SecurityConfig（目前現狀，全端點要求登入）

步驟 1：後端啟動，拿密碼

cd ai-products-selection-backend
.\gradlew.bat :ssds-api:bootRun

console 會印一組 UUID（Using generated security password: ...），帳號固定是 user，密碼每次重啟都變。

步驟 2：前端 裝 generator

cd ai-products-selection-frontend
npm install --save-dev @openapitools/openapi-generator-cli

openapitools.json：
{
  "$schema": "node_modules/@openapitools/openapi-generator-cli/config.schema.json",
  "spaces": 2,
  "generator-cli": { "version": "7.9.0" }
}

步驟 3：帶認證下載 spec，再從本地檔生成

curl -u user:<剛剛那組UUID> http://localhost:8080/api/v1/v3/api-docs -o openapi.json

package.json：

"generate:api": "openapi-generator-cli generate -i openapi.json -g typescript-angular -o src/app/api --additional-properties=ngVersion=21,providedInRoot=true,serviceSuffix=Service,withInterfaces=true,useSingleRequestParameter=true"

npm run generate:api

缺點：密碼每次重啟會變，每次都要重新 curl。這是暫時解法，建議儘快補 SecurityConfig 換版本 B。

版本 B 步驟 3：直接對 URL 生成（免帶認證）
"generate:api": "openapi-generator-cli generate -i http://localhost:8080/api/v1/v3/api-docs -g typescript-angular -o src/app/api --additional-properties=ngVersion=21,providedInRoot=true,serviceSuffix=Service,withInterfaces=true,useSingleRequestParameter=true"

步驟 4：.gitignore 加生成碼

/src/app/api

生成碼是衍生物，每人/CI 各自 generate:api 現生，不進版控（理由：避免手改被覆蓋覆蓋衝突、diff 無意義）。
